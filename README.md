# Plan Online — 데블스 플랜 3 게임 온라인

데블스 플랜 3에 나온 게임을 친구들과 브라우저에서 실시간으로 플레이하는 웹 게임 모음입니다.
(비공식 팬 프로젝트 — 게임 규칙만 참고했습니다.)

## 플레이 방법은 두 가지

### 1) GitHub Pages (P2P 모드, 서버 없이 바로)
**https://whdtlr4979-commits.github.io/DevilsPlan/**

- 방을 만든 사람(방장)의 브라우저가 게임 서버 역할을 하고, 다른 플레이어는 WebRTC(P2P)로 방장에게 직접 접속합니다.
- 접속 중계(시그널링)에는 [PeerJS](https://peerjs.com) 무료 공용 서버를 사용합니다. 게임 데이터는 브라우저끼리 직접 주고받습니다.
- 방장은 게임이 끝날 때까지 창을 닫지 마세요. 새로고침하면 방이 복구되고, 참가자는 자동으로 다시 연결됩니다.
- 회사·학교망이나 일부 모바일 통신망처럼 P2P가 막힌 네트워크에서는 연결이 안 될 수 있습니다. (PeerJS 기본 TURN 서버로 우회를 시도합니다)
- 방장의 브라우저가 전체 게임 상태를 갖고 있으므로, 개발자 도구를 열면 방장은 숨겨진 정보를 볼 수 있습니다. 공정성이 중요하면 아래의 서버 모드를 쓰세요.

`main`에 푸시하면 GitHub Actions(`.github/workflows/pages.yml`)가 테스트 후 `public/` 폴더를 자동 배포합니다.
처음 한 번은 저장소 **Settings → Pages → Build and deployment → Source** 를 **GitHub Actions** 로 지정해야 합니다.
('브랜치에서 배포' 모드여도 루트 `index.html` 이 게임 선택 화면(`public/`)으로 이동시킵니다.)

### 2) Node 서버 (서버 모드)
```bash
npm install
npm start        # http://localhost:3000
npm test         # 게임 엔진 / 방 로직 / 봇 시뮬레이션 테스트
```
서버가 게임 상태를 전부 갖고, 각 플레이어에게는 자신이 볼 수 있는 정보만 보냅니다. 포트는 `PORT` 환경 변수로 바꿀 수 있습니다.

## 게임

| 게임 | 상태 | 인원 |
|---|---|---|
| 러시안 룰렛 | ✅ 플레이 가능 | 6인 (빈자리는 봇) |
| 경매 빙고 | ✅ 플레이 가능 | 3~8인 (5명까지 봇이 채움) |

### 러시안 룰렛 플레이 방법
1. 닉네임 입력 → **방 만들기** → **초대 링크 복사**로 친구 초대 (또는 4자리 코드로 입장)
2. 방장이 **게임 시작** — 6명이 안 되면 빈자리는 봇이 채웁니다. 혼자라면 **봇 5명과 바로 연습하기**
3. 자리는 추첨으로 정해지고, 매 차례 공개 조사 / 비공개 조사 / 1·2칸 회전 / 조작 중 하나를 고릅니다.
4. 3명이 크레딧을 모두 쓰면 총구가 향한 사람부터 시계 방향으로 격발, 피탄된 2명이 탈락합니다.

**보드 읽는 법:** 실린더의 각 약실은 격발될 플레이어 방향에 그려집니다. 총구(빨간 삼각형)가 향한 플레이어가 약실 1, 시계 방향 다음 사람이 약실 2 … 순서이며, 총구를 회전하면 실린더 전체가 같이 돕니다.

**정보 공개 규칙**
- 처음 총구 방향은 무작위입니다.
- **조작 크레딧은 모두가 함께 채우는 공용 풀**에 1~3개씩 쌓입니다. 풀의 합계는 아무도 모릅니다.
  내 제출로 풀이 6 이상이 되면 그 자리에서 내가 인접 약실 2개를 골라 탄약을 교환하고, 초과분은 소멸, 풀은 0으로 초기화됩니다.
- 공개 조사와 회전은 누가 무엇을 했는지 전체 공개됩니다.
- **비공개 조사 · 조작 · 패스는 다른 플레이어에게 모두 똑같이 "비공개 행동"으로만 발표**됩니다.
  어느 약실을 조사했는지, 얼마를 냈는지, 조작이 실행됐는지, 크레딧이 바닥났는지 알 수 없습니다.
  그래서 누가 크레딧을 다 썼는지도 비공개이고, 게임은 예고 없이 끝납니다.
- 크레딧이 0인 플레이어도 차례를 받아 자동으로 패스합니다. 무작위로 몇 초 기다리므로 타이밍으로도 티가 나지 않습니다.
- 내가 확인한 약실 정보 뒤에 다른 사람의 비공개 행동이 있었다면, 조작됐을 수도 있으므로 점선(불확실)으로 표시됩니다.
- 3번째 크레딧 소진자가 나오는 즉시 게임이 끝나고, 총알 2발이 모두 나오면 격발을 멈춥니다. 게임이 끝나면 모든 기록이 공개됩니다.
- 봇도 사람과 똑같이 자기 시점의 정보만 사용합니다.
- 게임 중 연결이 끊긴 플레이어는 8초 뒤 봇이 대신 행동합니다. 같은 브라우저로 다시 접속하면 이어서 플레이합니다.
- 서버 모드에서는 방장이 나가면 다른 사람에게 방장이 넘어가고, P2P 모드에서는 방이 닫힙니다.

### 경매 빙고
경매로 도형을 낙찰받아 내 빙고판에 최대한 많은 빙고를 완성하는 게임. 7라운드 동안 ① 도형 상자(○△☆)에 티켓 넣기 → ② 코인 비공개 입찰(+낙찰가 발표)을 반복하고, 끝나면 획득한 도형을 빙고판에 자동 배치해 순위를 정합니다.

- 누가 어느 상자에 티켓을 넣었는지는 **넣는 즉시** 모두에게 공개됩니다.
- 입찰은 **최소 1원**. 시간 안에 1원 이상 내지 못하면(코인이 없으면 입찰 시작 때) **즉시 탈락** — 남은 라운드에서 빠지고 최하위(먼저 탈락할수록 아래).
- 낙찰자는 그 도형에 **입찰한** 인원 수만큼 획득, 동률이면 나눠 갖고 소수점은 버림.
- 하단의 **내 빙고판**은 언제든 열어 볼 수 있고, 낙찰받았다고 생각하는 칸을 메모할 수 있습니다 (나만 보는 메모). 실제 획득 결과는 끝날 때 공개.

**온라인 버전 해석 (원문에 명시되지 않은 부분)**
- 공통 빙고판: 가로·세로 줄마다 세 도형이 하나씩 (`○△☆ / △☆○ / ☆○△`)
- 제한 시간은 방장이 대기실에서 선택: 빠름 30초/45초, 보통 1분/1분30초, 여유 3분/5분, 원작 15분/20분
- 시간 안에 티켓을 안 넣으면 무작위 상자
- 아무도 입찰하지 못한 상자는 유찰, 낙찰가가 가장 높은 도형이 여럿(동률)이면 모두 시크릿
- 순위의 '남은 코인의 양'은 남은 금액(원) 기준
- 봇도 공개 정보와 자기 입찰만 보고 판단하며, 탈락하지 않도록 남은 라운드 수만큼 코인을 남겨 둠

## 구조

```
public/                              GitHub Pages 로 배포되는 정적 사이트 (서버 모드에서도 그대로 사용)
  index.html                         게임 선택 대시보드
  config.js                          기본 설정 (P2P 모드). 서버 모드에서는 서버가 대신 내려줌
  css/common.css, css/app.css        디자인 시스템 / 공용 게임 레이아웃
  js/games.js                        대시보드 게임 목록
  js/net.js                          네트워크 계층: server(Socket.IO) / p2p(PeerJS)
  js/shell.js                        공용 앱 셸: 입장·대기실·채팅·룰·효과음·재접속
  shared/room.js                     공용 방 로직 (브라우저 P2P 호스트·Node 서버 공용)
  shared/<게임>/engine.js            순수 게임 규칙 + 플레이어별 정보 은닉
  shared/<게임>/bot.js               봇 AI (자기 시점 정보만 사용)
  shared/<게임>/adapter.js           게임 규칙을 공용 방에 연결
  games/<게임>/                      게임 화면
  vendor/peerjs-1.5.4.min.js         PeerJS (MIT)
server/
  index.js                           Express + Socket.IO 서버 (서버 모드)
  roomSocket.js                      공용 방을 Socket.IO 네임스페이스에 연결
test/                                node:test 테스트
```

### 새 게임 추가하기
1. `public/shared/<게임>/` 에 `engine.js`, `bot.js`, `adapter.js` 작성 (어댑터 인터페이스는 `shared/room.js` 주석 참고)
2. `public/games/<게임>/` 에 화면 작성 — `js/shell.js` 를 쓰면 입장·대기실·채팅은 공짜 (경매 빙고 참고)
3. `server/index.js` 에 `attachRoom(io.of('/<게임>'), require(어댑터))` 한 줄 추가
4. `public/js/games.js` 에 항목 추가
